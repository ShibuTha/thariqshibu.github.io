The objective was to analyze toy sales data and create an interactive dashboard that provides insight into revenue, profitability, product performance, store performance, and inventory.

Tools & Technologies

  • Microsoft Power BI
  • DAX
  • Power Query
  • Data Modeling
  • Microsoft Excel

Key Metrics

Technical Implementation
